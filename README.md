# Smart File Manager

A Python-based file management application that helps users manage files easily through a command-line interface.

## Features

✅ Search Files  
✅ Rename Files  
✅ Move Files  
✅ Delete Files (Safe Delete)  
✅ Recover Deleted Files  
✅ Compress Folders into ZIP Files  
✅ Duplicate File Finder  

## Technologies Used

- Python
- OS Module
- Shutil Module
- File Handling
- Git & GitHub

## Functionalities

### Search File
Searches for files inside a given folder.

### Rename File
Renames an existing file.

### Move File
Moves files from one folder to another.

### Delete File
Moves files into a recycle bin instead of permanently deleting them.

### Recover File
Restores deleted files from the recycle bin.

### Compress File
Creates ZIP files from folders.

### Duplicate Finder
Detects duplicate files by comparing file contents.
